# MindPulse

Mental sağlık ve ruh sağlığını desteklemek için geliştirilen web tabanlı bir uygulama.

## 📋 Açıklama

MindPulse, kullanıcıların mental sağlıklarını izlemesine ve iyileştirmesine yardımcı olan interaktif bir web uygulamasıdır. İçeriği eğitici kaynaklar, meditasyon rehberliği ve kişisel takip araçlarını içerir.

## 🛠️ Teknolojiler

- **HTML5**
- **CSS3**
- **JavaScript**

## 🚀 Başlangıç

```bash
# Repository'yi klonlayın
git clone https://github.com/YunusEdizer/MindPulse.git

# Proje klasörüne gidin
cd MindPulse

# index.html dosyasını tarayıcıda açın
```

## 🌟 Özellikler

- Ruh sağlığı takibi
- Meditasyon rehberliği
- Kişisel notlar ve günlük
- Sağlık ipuçları ve kaynaklar
